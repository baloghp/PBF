# Coach Diary — Default Template

**Purpose:** Default content for the **Coach diary** rich-text field. Pre-populate this (or an HTML version) when a new nomination is assigned to a coach or when the coach opens the diary for the first time. The coach edits the diary in place, ticking off checks and filling placeholders.

**Usage:** Store this text as the default for the diary field in your CMS (e.g. Nominations collection or a linked CoachDiary collection). Coaches use the same diary throughout Stage 1 for that nomination.

**Rich-text (HTML) version:** The same content (sections 1.1–1.2 and 2–7 only) is available as HTML in **Coach-Diary-Default-Template.html** for pasting into WIX or other rich-text fields that accept HTML.

---

## Copy below for default rich-text content

The following block is the template (Markdown). For **HTML rich-text**, use **Coach-Diary-Default-Template.html** instead. Replace placeholders in square brackets as you go.
