## Slide 7 - Stage 1 Process Flow

**Title:** The Stage 1 Workflow  
**Process steps:**
1. Nominee submits nomination via WIX platform
2. Coach performs intake and completeness check
3. Coach confirms eligibility
4. COI check and recusal handling (if needed)
5. Assessors score independently (0-5 scale, 9 criteria)
6. Score moderation if variance > 2 points
7. Shortlist recommendation and rationale
8. Feedback drafted for non-shortlisted nominees

## Slide 15 - How to Report Bugs

**Title:** Defect Reporting Standard  
**Post bugs in the shared Discord bug channel using this format:**

```
**Bug Title:** [Short description]
**User Role:** [Nominee / Coach / Assessor]
**Group:** [Group 1 / Group 2 / etc.]
**Environment:** [Browser / Device]
**Steps to Reproduce:**
1. ...
2. ...
3. ...
**Expected Result:** [What should have happened]
**Actual Result:** [What actually happened]
**Severity:** [Critical / High / Medium / Low]
**Evidence:** [Screenshot / video attached]
```

**Severity guide:**
- **Critical:** Process cannot continue at all.
- **High:** Core function broken; poor or no workaround.
- **Medium:** Partial impact; workable workaround exists.
- **Low:** Cosmetic or wording issue.

**Why shared channel?** Other groups can see your bug and attempt to replicate it, which helps us confirm whether it is a real defect or a one-off.
