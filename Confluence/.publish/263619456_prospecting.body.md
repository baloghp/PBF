## 4. How to find companies

### 4.1 LinkedIn

1. **Company search** → Location **München** → Industry *Software* / *Professional Training* / *Construction* / *Airlines*.
2. Filter **500+ employees** for Tier 2–3; **10–500** for contractors and Community.
3. Check **Posts** tab — active marketing = easier Amplification ask.
4. **Similar companies** from one good lead (e.g. one PM tool → others in category).

## 5. How to find the marketing department

### 5.1 Job titles to search *(DE + EN)*

| Role | Notes |
| --- | --- |
| **Leiter Marketing** / **Head of Marketing** | Default target — B2B SaaS and consultancies |
| **Marketing Manager** / **Senior Marketing Manager** | Often owns campaigns and LinkedIn |
| **Corporate Communications** / **Unternehmenskommunikation** | Larger firms; may own partnerships |
| **PR Manager** / **Presse** | Media-heavy partners |
| **Partner Marketing** / **Alliances** | Best for co-marketing ask (Tier 3) |
| **Field Marketing** / **DACH Marketing** | Regional campaigns — good for Munich-based outreach |
| **Brand Manager** | Tier 1–3 logo/co-branding |
| **Event Marketing** / **Messe** | Tier 1 ceremony/hospitality adjacent |
| **CSR Manager** / **Nachhaltigkeit** | Secondary path if no marketing response |

**Avoid first contact:** Sales, HR, Product (unless small company — then **Geschäftsführung** / CEO).

### 5.2 Where contact details hide

| Source | What you get |
| --- | --- |
| **LinkedIn** | Name, role, DM or InMail |
| **Company website → Impressum** | Legal entity, sometimes general email |
| **Website → Kontakt / Presse / Newsroom** | `presse@` · `marketing@` · `info@` (last resort) |
| **Press releases** | Named PR contact at bottom |
| **LinkedIn company page → People** | Filter *Marketing* + *Munich* |
| **Email pattern** | `vorname.nachname@firma.de` — verify with Hunter.io / MailTester if needed |

### 5.3 German email / call approach

**Email subject (DE option):**  
`Projekt Contractor of the Year — In-kind-Partnerschaft (LinkedIn, Sep–Okt 2026)`

**Opening line (DE):**  
*Guten Tag [Herr/Frau Name], ich schreibe Ihnen im Namen des Project Contractor of the Year Award (Project Business Foundation) — wir suchen für den ersten Live-Zyklus In-kind-Partner für Sichtbarkeit während des Nominierungsfensters (1. Sep. – 31. Okt. 2026). Kein Cash-Sponsoring — gegenseitige LinkedIn-Reichweite und klare Partnerschaftsbestätigung.*

Then switch to English if their LinkedIn profile and posts are English-only.

**Phone (if Impressum lists number):** Ask for **Marketing** or **Presse** — not switchboard sales.
