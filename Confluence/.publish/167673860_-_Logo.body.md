## Site style guide (match Wix award page)

Use for LinkedIn, banners, Canva — not the seal alone.

### Key fonts

| Use | Font | Size |
| --- | --- | --- |
| Section headings | **Cinzel**, serif | 40px |
| Hero-style titles | **Bree Thin Oblique** | 40px |
| Body | **Caudex** or **Avenir Light** | 16–18px |
| Hero tagline | **Barlow** | 30px, `#5E5F68` |
| Timeline dates | **Playfair Display** | 23px |
| Primary CTA | **Avenir Light** | 15px, white on `#282626` |

### Key colours

| Hex | Role |
| --- | --- |
| `#48180D` | Page background (dark burgundy) |
| `#902F1A` | Hero overlay |
| `#8B1E2D` | Seal / accent burgundy |
| `#282626` | CTA button, timeline text |
| `#4BD1A0` | Category accent (Medium / Large — use sparingly) |
| `#F7F4F4` | Warm off-white panels |
