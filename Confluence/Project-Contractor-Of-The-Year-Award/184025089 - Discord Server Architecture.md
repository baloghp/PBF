# Discord Server Architecture

- Page ID: `184025089`
- URL: `https://ittd.atlassian.net/wiki/spaces/PBF/pages/184025089`

## Body

This page documents proposed Discord architecture for the CotY process.

It includes:

1. Proposed roles and access model
2. Channel architecture mapped to the process flow
3. Example operational Discord functions and bot workflows

Key concepts covered:

* Stage-aligned private channels
* Role-based visibility (intake, screening, judging, comms)
* Embargo and publication-prep channels
* Slash commands and automated routing for nominee workflows
* Decision log patterns for auditable records
