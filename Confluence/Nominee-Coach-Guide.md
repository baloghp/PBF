# Nominee Coach Guide

**Parent page:** [Roles and RACI](https://ittd.atlassian.net/wiki/spaces/PBF/pages/117964816)

---

## Overview

The Nominee Coach guides assigned nominees through the entire process from submission to award. Each coach is assigned an equal number of nominees from each category (Small, Medium, Large) to ensure balanced workload and category expertise.

**Key Principle:** One coach per nominee - you are their single point of contact throughout the entire process.

---

## Key Responsibilities

You are responsible for your assigned nominees from start to finish:

1. **Submission Phase:** Guide through submission, check completeness, verify eligibility
2. **Stage 1 Phase:** Coordinate assessment, assign assessors, moderate scores, notify of results
3. **Stage 2 Phase:** Prepare nominees for presentations, coordinate with assessors for preparation help, schedule presentations
4. **Award Phase:** Notify of results, coordinate publication materials

---

## Process Phases

### Submission Phase (1.1-1.2)

**Timeline:** Within 24 hours of submission receipt

#### Step 1: Initial Contact & Introduction

When a nominee is assigned to you:

1. **Send welcome email** (within 24 hours of assignment):
   - Introduce yourself as their Nominee Coach
   - Explain your role as their single point of contact
   - Provide your contact information
   - Set expectations for communication (response time, preferred method)
   - Link to relevant resources: [Submission Package](https://ittd.atlassian.net/wiki/spaces/PBF/pages/98598913), [Process Map](https://ittd.atlassian.net/wiki/spaces/PBF/pages/117866524)

2. **Review their submission status**:
   - Check if submission is in draft or submitted
   - Review what has been completed
   - Identify any immediate gaps

#### Step 2: Completeness Check (Within 24 hours of submission)

Use this checklist to verify completeness:

**Written Submission (≤2,000 words):**
- [ ] Objectives clearly stated
- [ ] Scope/baseline defined
- [ ] Outcomes vs baseline described
- [ ] Interface & governance explained
- [ ] Commercial/contract model and liquidity addressed
- [ ] Risk handling documented
- [ ] Integrity controls described
- [ ] Word count within limit (≤2,000 words)

**Required Sections:**
- [ ] "What Makes This Exemplary?" section completed (500 words)
- [ ] "Impact Measurement & Transformation" section completed (300 words)
- [ ] "Lessons Learned & Industry Contribution" section completed (300 words)

**Evidence Artifacts:**
- [ ] Draft contract matrix uploaded
- [ ] Customer-contractor interface RACI uploaded
- [ ] People Development metric provided (0%, 0-5%, or 5%+)
- [ ] Code of conduct acknowledgment uploaded
- [ ] Integrity plan uploaded

**Client Assessment Form:**
- [ ] Client Assessment Form completed and signed
- [ ] Total score and % achieved entered in nomination form
- [ ] Evidence notes provided for ratings ≥8 or ≤4

**Other Requirements:**
- [ ] Publication consent accepted
- [ ] Data retention policy acknowledged
- [ ] GDPR guidance acknowledged
- [ ] All required fields in nomination form completed

**GDPR Compliance Check:**
- [ ] Review for excessive personal data (names, emails, phone numbers)
- [ ] Flag if personal data needs to be minimized
- [ ] Provide guidance on using roles/titles instead of names

#### Step 3: Eligibility Verification

Verify the following eligibility criteria:

- [ ] **Project type:** Cross-corporate customer-contractor project
- [ ] **Contractor status:** Independent contractor for paying client under contract
- [ ] **Completion window:** Project completed within last 2 years (2024-2025) OR currently running
- [ ] **Category classification:** Headcount-based category correctly identified:
  - Small: 1-25 people in customer projects
  - Medium: 26-100 people in customer projects
  - Large: 101+ people in customer projects

#### Step 4: Handle Incomplete Applications

**If submission is incomplete:**

1. **Document missing items** - Create a list of specific missing requirements
2. **Send notification email** to nominee:
   - List all missing items clearly
   - Provide links to relevant guidance
   - Set deadline for completion (typically 7-14 days)
   - Offer to answer questions
3. **Set reminder** to follow up if not completed by deadline
4. **Follow up** if deadline approaches:
   - Send reminder 2 days before deadline
   - Offer assistance if they're struggling
5. **If still incomplete after deadline:**
   - Escalate to Project Manager
   - Document reason for rejection
   - Send rejection notification with explanation

**If submission is complete and eligible:**

1. **Mark as "Ready for Assessment"** in platform
2. **Update application status** to "Under Review"
3. **Send confirmation email** to nominee:
   - Confirm completeness
   - Provide expected timeline for Stage 1 assessment
   - Set expectations for next steps

#### Step 5: Respond to Nominee Questions

**Response SLA:** Within 48 hours (or as defined by project)

**Common questions and responses:**

- **"What happens next?"** → Explain Stage 1 assessment process and timeline
- **"How long does the process take?"** → Provide overall timeline
- **"Can I edit my submission?"** → Explain if edits are allowed (typically only before final submission)
- **"What if my client hasn't completed the assessment form?"** → Provide guidance on following up with client, offer template email

**Escalation:** If you cannot answer a question:
- Consult with other Nominee Coaches for consistency
- Escalate to Project Manager for policy questions
- Document question and answer for future reference

### Stage 1 Assessment (2.1)

**Timeline:** Assignment within X days, Assessment complete within X days (as defined by project SLA)

#### Step 1: Assign Assessors

**Before assignment:**

1. **Review available assessors:**
   - Check assessor availability and workload
   - Review assessor category expertise
   - Check COI declarations for your nominees

2. **Assign assessors** (minimum 2-3 per nomination):
   - Ensure balanced workload across assessors
   - Match assessor expertise to nominee category
   - Verify COI-free status
   - Document assignments in platform

3. **Send assignment notification** to assessors:
   - Provide nominee information (category, project type)
   - Set assessment deadline
   - Link to Evaluation Framework and Assessor Guide
   - Provide access to nomination materials

#### Step 2: Monitor COI Recusals

**If assessor reports COI:**

1. **Document recusal** immediately:
   - Record reason for recusal
   - Update audit trail
   - Remove assessor from assignment

2. **Assign alternate assessor:**
   - Check COI status of alternate
   - Ensure minimum 2-3 assessors remain
   - Notify alternate assessor

3. **Verify quorum:**
   - Ensure minimum 2-3 independent reviewers after recusals
   - If quorum cannot be met, escalate to Project Manager

#### Step 3: Monitor Assessment Progress

**Track assessment status:**

1. **Check assessment completion status** regularly
2. **Send reminders** if assessments are approaching deadline
3. **Follow up** with assessors if delays occur
4. **Escalate** to Project Manager if assessors are unresponsive

#### Step 4: Review Inter-Rater Reliability

**When assessments are complete:**

1. **Compare scores** from multiple assessors
2. **Calculate median score** for each criterion
3. **Identify discrepancies:**
   - Flag scores >2 points from median
   - Document significant discrepancies

4. **If discrepancy >2 points:**
   - Initiate moderation discussion
   - Contact assessors to discuss differences
   - Facilitate discussion to reach consensus or provide justification
   - Document moderation process and outcome

5. **Calculate moderated average:**
   - Use consensus scores where available
   - Use moderated average for remaining scores
   - Document final scores

#### Step 5: Calculate Scores and Rank

1. **Calculate final scores** per nomination:
   - Apply weights to each criterion
   - Calculate weighted average
   - Include Client Assessment Form score (if applicable)

2. **Rank nominations within category:**
   - Small organizations (1-25 people)
   - Medium organizations (26-100 people)
   - Large organizations (101+ people)

3. **Prioritize high Innovation & Industry Advancement scores:**
   - Note nominations scoring 4-5 on this criterion
   - Consider this in shortlisting decisions

4. **Select top N per category** for Stage 2 (number to be determined by project)

5. **Document shortlist decisions:**
   - Record rationale for shortlisted nominations
   - Record rationale for non-shortlisted nominations
   - Prepare feedback for non-shortlisted nominees

#### Step 6: Notify Nominees of Results

**For shortlisted nominees:**

1. **Prepare shortlist notification:**
   - Congratulate on shortlisting
   - Explain next steps (Stage 2 presentation)
   - Provide presentation requirements and timeline
   - Set expectations for Stage 2

2. **Send notification** via email/platform

3. **Update application status** to "Shortlisted"

**For non-shortlisted nominees:**

1. **Prepare feedback notification:**
   - Thank for participation
   - Provide constructive feedback on areas for improvement
   - Reference specific criteria where scores were lower
   - Encourage future applications
   - Offer to discuss feedback if requested

2. **Send notification** via email/platform

3. **Update application status** to "Not Shortlisted"

**Template for feedback:**
- "Thank you for your submission. While your project demonstrated [strengths], the evaluation identified opportunities for improvement in [specific areas]. We encourage you to [specific actions] for future submissions."

### Stage 2 Preparation (2.2)

**Timeline:** Schedule presentations within X days of shortlisting

#### Step 1: Prepare Nominees for Presentations

**Send presentation requirements:**

1. **Presentation format:**
   - Maximum 10 slides
   - 20-minute presentation + 15-minute Q&A
   - Online format (platform to be determined)

2. **Required coverage areas:**
   - Outcomes vs baseline
   - Interface/governance
   - Commercial/liquidity
   - Risk management
   - Integrity controls
   - **What makes this exemplary?** (from "What Makes This Exemplary?" section)
   - **Measurable impact and transformation** (from "Impact Measurement & Transformation" section)
   - **Lessons learned and industry contribution** (from "Lessons Learned & Industry Contribution" section)

3. **Required materials:**
   - Signed Client Assessment summary
   - At least two artifacts (interface RACI snapshot, People Development metric)

4. **Presentation recording consent:**
   - Explain that presentation will be recorded
   - Obtain consent for recording and potential publication
   - Provide consent form

#### Step 2: Coordinate Preparation Support

**If assessors are available to help:**

1. **Contact assessors** who evaluated the nominee in Stage 1
2. **Request preparation support:**
   - Ask if assessor can provide coaching/feedback
   - Coordinate meeting between assessor and nominee
   - Provide assessor with presentation requirements

3. **Facilitate preparation:**
   - Help nominee understand what judges are looking for
   - Review presentation draft if requested
   - Provide feedback on presentation structure

#### Step 3: Schedule Presentations

1. **Coordinate with finalists:**
   - Contact each shortlisted nominee
   - Identify available time slots
   - Account for time zones
   - Confirm preferred dates/times

2. **Coordinate with judging panel:**
   - Confirm panel availability
   - Schedule 20-minute presentation + 15-minute Q&A slots
   - Allow buffer time between presentations

3. **Send calendar invitations:**
   - Include meeting link
   - Include presentation requirements
   - Include Q&A question template (if available)
   - Set reminders

4. **Confirm attendance:**
   - Follow up 2 days before presentation
   - Confirm nominee and panel availability
   - Reschedule if needed

#### Step 4: Verify COI for Judging Panel

**Before presentations:**

1. **Review COI declarations** for all panel members
2. **Check for conflicts** with your nominees
3. **Document any recusals** if COI identified
4. **Verify quorum** after recusals
5. **Notify Project Manager** if quorum cannot be met

#### Step 5: Facilitate Presentations

**During presentation:**

1. **Introduce finalist** to judging panel
2. **Track time:**
   - 20 minutes for presentation
   - 15 minutes for Q&A
   - Provide time warnings (5 minutes remaining, 1 minute remaining)

3. **Manage Q&A session:**
   - Use standardized question template
   - Ensure questions probe: "Why should you win? What makes this exemplary?"
   - Record responses
   - Manage any technical issues

4. **Handle recusals** if COI arises during presentation:
   - Document recusal immediately
   - Ensure quorum maintained
   - Continue with remaining panel members

5. **Record presentation** (with consent)

**After presentation:**

1. **Thank nominee** for participation
2. **Confirm next steps** and timeline
3. **Update application status** to "Stage 2 Complete"

---

### Award Phase (3.1-3.2)

**Timeline:** Notifications within X days of decision

#### Step 1: Prepare Notifications

**For winners:**

1. **Obtain winner notification template** from Communications Coordinator
2. **Customize template:**
   - Include nominee name/organization
   - Include award category
   - Include recognition details
   - Include next steps (publication, ceremony, etc.)
   - Include publication consent reminders

3. **Prepare under embargo** until official announcement

**For finalists (non-winners):**

1. **Obtain finalist notification template** from Communications Coordinator
2. **Customize template:**
   - Recognize finalist status
   - Appreciate participation
   - Provide feedback on areas of strength
   - Invite to apply in future cycles

**For non-finalists (if not already notified):**

1. **Use standard notification template**
2. **Thank for participation**
3. **Provide general feedback**

#### Step 2: Send Notifications

1. **Review notifications** for accuracy
2. **Send winner notifications** (under embargo)
3. **Send finalist notifications**
4. **Send non-finalist notifications** (if applicable)
5. **Update application statuses** in platform:
   - Winners: "Winner"
   - Finalists: "Finalist"
   - Others: "Not Selected"

6. **Track notification delivery:**
   - Confirm receipt
   - Follow up if no response

#### Step 3: Coordinate Publication Materials

**For winners and top 3 finalists:**

1. **Coordinate with Communications Coordinator:**
   - Provide nominee contact information
   - Facilitate case story development
   - Coordinate publication consent

2. **Support nominee** in preparing materials:
   - Help gather additional information if needed
   - Review case story drafts if requested
   - Ensure publication consent obtained

3. **Coordinate embargo management:**
   - Ensure nominees understand embargo requirements
   - Monitor compliance with embargo
   - Coordinate release timing

## Common Issues & Solutions

### Issue: Nominee hasn't submitted Client Assessment Form

**Solution:**
1. Contact nominee to check status
2. Provide guidance on following up with client
3. Offer template email for nominee to send to client
4. Set deadline for completion
5. Escalate if deadline missed

### Issue: Submission is incomplete after deadline

**Solution:**
1. Document all missing items
2. Send final reminder with clear deadline
3. Offer assistance if they're struggling
4. If still incomplete, escalate to Project Manager
5. Send rejection notification with explanation

### Issue: Assessor reports COI

**Solution:**
1. Document recusal immediately
2. Assign alternate assessor
3. Verify quorum maintained
4. Update audit trail
5. If quorum cannot be met, escalate to Project Manager

### Issue: Significant scoring discrepancy (>2 points)

**Solution:**
1. Review both assessments carefully
2. Contact assessors to discuss differences
3. Facilitate moderation discussion
4. Document discussion and outcome
5. Use consensus or moderated average

### Issue: Nominee cannot attend scheduled presentation

**Solution:**
1. Contact nominee immediately
2. Identify alternative time slots
3. Coordinate with judging panel for rescheduling
4. Reschedule presentation
5. Update calendar invitations

### Issue: Technical problems during presentation

**Solution:**
1. Have backup communication method ready
2. Test technology before presentation
3. Have technical support contact available
4. Document any issues
5. Reschedule if technical problems cannot be resolved

## Escalation Procedures

### When to Escalate to Project Manager

- Quorum cannot be met after COI recusals
- Nominee repeatedly misses deadlines
- Significant process issues or blockers
- Policy questions you cannot answer
- Disputes that cannot be resolved
- Technical issues that block progress

### How to Escalate

1. **Document the issue:**
   - Describe the problem clearly
   - Include relevant details
   - Note what you've already tried

2. **Contact Project Manager:**
   - Use preferred communication method
   - Include nominee information
   - Request guidance or decision

3. **Follow up:**
   - Check for response
   - Implement guidance received
   - Document resolution
